# Release notes

Write every GitHub release note in English and Simplified Chinese. Keep the two sections equivalent, including requirements and installation steps. Start from [TEMPLATE.md](TEMPLATE.md), save the final note as `vX.Y.Z.md`, and publish it with `gh release create ... --notes-file docs/releases/vX.Y.Z.md` or update an existing release with `gh release edit ... --notes-file docs/releases/vX.Y.Z.md`.
