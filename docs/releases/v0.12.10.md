### WordPing for language learners

This release brings the keyless WordPing workflow together with its current lookup and review features. No Youdao AI Cloud key or account is needed.

- Translate words and phrases with configurable native and learning languages. Set a direction for a lookup with syntax such as `wp es>zh trabajo`.
- See results from Youdao, Iciba, Baidu, Wiktionary, Apple Translation, and MyMemory as they arrive. Provider order is configurable.
- Read dictionary meanings in compact provider rows. Press **⌘L** for a long result; Return still copies the complete translation.
- Hold **⌥ Option** to see available phonetics or pinyin on Youdao and Iciba results, then press **⌥ Return** for online pronunciation.
- Use small, muted outline icons to identify providers while leaving subtitles for meanings and language direction.
- Get English spelling corrections and word-completion suggestions.
- Save words for spaced review, reverse recall, reminders, backup, restore, and CSV export.
- Preview query-specific web provider pages with Shift. Apple Translation has no web preview because its result is produced on-device.
- Type `wp :update` to check GitHub Releases. When a newer version is available, press Return to download and open it in Alfred.
- Read these release notes in Alfred's import window when installing or upgrading WordPing.

### Requirements

- Apple silicon Mac
- Alfred 5.5 or newer with Powerpack
- Internet connection for web lookups and release updates
- macOS 26 with installed language models for optional Apple Translation results

Download the `.alfredworkflow` asset below and open it with Alfred. Set the selected-text hotkey in Alfred Preferences if you want double-tap Option translation.

### 面向语言学习者的 WordPing

本版整合了无需密钥的 WordPing 工作流及现有的查词和复习功能。无需有道智云应用密钥或账号。

- 自行设置母语和学习语言，翻译单词与短语；也可以用 `wp es>zh trabajo` 等语法指定翻译方向。
- 有道、金山词霸、百度、维基词典、Apple 翻译和 MyMemory 的结果会在返回时逐条显示。可以调整服务来源的顺序。
- 在紧凑的来源结果中查看词义。结果较长时按 **⌘L** 查看全文；按 Return 仍会复制完整译文。
- 在有道和金山词霸结果上按住 **⌥ Option**，查看可用的音标或拼音；按 **⌥ Return** 播放在线发音。
- 用低调的小型线框图标区分来源，让副标题留给词义和语言方向。
- 查看英文拼写纠正和单词补全建议。
- 保存生词，并使用间隔复习、反向回忆、提醒、备份、恢复及 CSV 导出功能。
- 按 Shift 预览与查询对应的网页服务页面。Apple 翻译在设备上生成结果，因此没有网页预览。
- 输入 `wp :update` 检查 GitHub Releases。如有新版本，按 Return 下载并在 Alfred 中打开。
- 安装或升级 WordPing 时，可在 Alfred 的导入窗口中阅读这些更新说明。

### 使用要求

- Apple 芯片 Mac
- Alfred 5.5 或更高版本，且已购买 Powerpack
- 网页查词和版本更新需要网络连接
- 可选的 Apple 翻译结果需要 macOS 26 和已安装的相应语言模型

下载下方的 `.alfredworkflow` 文件，使用 Alfred 打开即可安装。如需双击 Option 翻译选中文本，请在 Alfred 设置中配置该快捷键。
