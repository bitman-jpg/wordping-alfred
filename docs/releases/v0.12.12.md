### What's new

- Open Privacy & Security automatically after a likely macOS security block of `tjs`, once per bundled runtime. Alfred shows instructions for allowing it and retrying the lookup.
- Add illustrated security setup instructions to both English and Chinese READMEs and guidance in Alfred's installation window.

macOS approval still requires your confirmation. If Settings does not open automatically, dismiss the warning, open System Settings → Privacy & Security, scroll to Security, and select Allow Anyway (or Open Anyway) for `tjs`. Then retry `wp hello`.

### Requirements and installation

Apple silicon Mac, Alfred 5.5 or newer with Powerpack, and internet access for web lookups. Optional Apple Translation requires macOS 26 and installed language models.

Download the `.alfredworkflow` asset below and open it with Alfred.

### 更新内容

- 检测到 macOS 可能拦截 `tjs` 后，自动打开“隐私与安全性”（同一个运行程序仅自动打开一次），并在 Alfred 中提示如何允许运行及重试查词。
- 中英文 README 新增带截图的安全设置说明；Alfred 安装窗口中也提供操作指引。

仍需由你亲自确认 macOS 的允许操作。如果设置未自动打开，请关闭警告，打开“系统设置 → 隐私与安全性”，向下滚动到“安全性”，为 `tjs` 选择“仍要允许”或“仍要打开”，然后重试 `wp hello`。

### 使用要求与安装

需要 Apple 芯片 Mac、Alfred 5.5 或更新版本及 Powerpack；网页查词需要联网。可选的 Apple 翻译需要 macOS 26 和已安装的语言模型。

下载下方的 `.alfredworkflow` 文件，使用 Alfred 打开即可安装。
