### What's new

- Add `wp :dictionaries` to install or update ECDICT and CC-CEDICT independently of WordPing releases.
- Add `ecdict` (English → Chinese) and `cedict` (Chinese → English) before Apple in the default provider list; missing packs install in the background on first use.
- Keep downloaded dictionary indexes in Alfred's persistent workflow-data directory and replace them only after a successful import.
- Remove the bundled Langdao dictionary and its provider; ECDICT and CC-CEDICT are the maintained offline replacements.
- Format system Oxford articles as concise senses and expose the complete entry through a large, scrollable, local Shift preview.

### Requirements and installation

Apple silicon Mac, Alfred 5.5 or newer with Powerpack, and internet access for web lookups and downloadable dictionary updates. Optional Apple Translation requires macOS 26 and installed language models.

Download the `.alfredworkflow` asset below and open it with Alfred.

### 更新内容

- 新增 `wp :dictionaries`，无需等待 WordPing 发版即可安装或更新 ECDICT 与 CC-CEDICT。
- 在默认来源列表的 Apple 之前新增 `ecdict`（英译中）与 `cedict`（中译英）；首次使用时会在后台自动安装缺少的词库。
- 下载的词典索引保存在 Alfred 的持久工作流数据目录中；只有完整导入成功后才会替换旧索引。
- 移除内置朗道词典及其来源；由 ECDICT 与 CC-CEDICT 作为持续维护的离线替代方案。
- 将系统牛津文章整理为简洁释义，并可按住 Shift 在大型、可滚动的本地预览中查看完整词条。

### 使用要求与安装

需要 Apple 芯片 Mac、Alfred 5.5 或更新版本及 Powerpack；网页查词和可下载词典更新需要联网。可选的 Apple 翻译需要 macOS 26 和已安装的语言模型。

下载下方的 `.alfredworkflow` 文件，使用 Alfred 打开即可安装。
