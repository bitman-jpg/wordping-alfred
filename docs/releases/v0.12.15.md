### What's new

- Replace separate macOS Gatekeeper approval prompts for `tjs`, word suggestions, and Apple Translation with one explicit **Trust and enable WordPing** action in Alfred.
- Limit the trust action to removing the quarantine attribute from WordPing's three bundled executables; no other files or system security settings are changed.
- Skip the trust action automatically when macOS did not quarantine the installed workflow.

### Requirements and installation

Apple silicon Mac and Alfred 5.5 or newer with Powerpack. Internet access is required for web lookups and downloadable dictionary updates. Optional Apple Translation requires macOS 26 and installed language models.

Download the `.alfredworkflow` asset below and open it with Alfred. If WordPing shows **Trust and enable WordPing** on first use, select it only if you downloaded the workflow from this official release page, press Return, and then retry your lookup.

### 更新内容

- 将 macOS 分别针对 `tjs`、单词建议和 Apple 翻译显示的 Gatekeeper 批准提示，改为 Alfred 中一次明确的 **Trust and enable WordPing** 操作。
- 信任操作仅移除 WordPing 自带的三个可执行文件上的隔离属性，不会更改其他文件或系统安全设置。
- 如果 macOS 未隔离已安装的工作流，则自动跳过信任操作。

### 使用要求与安装

需要 Apple 芯片 Mac、Alfred 5.5 或更新版本及 Powerpack。网页查词和可下载词典更新需要联网。可选的 Apple 翻译需要 macOS 26 和已安装的语言模型。

下载下方的 `.alfredworkflow` 文件，使用 Alfred 打开即可安装。如果 WordPing 首次使用时显示 **Trust and enable WordPing**，请仅在工作流来自此官方发布页时选中该项并按 Return，然后重试查询。
