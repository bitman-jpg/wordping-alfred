## English

WordPing now supports language learners beyond English. Choose your native and learning languages to translate in either direction; detected third-language input translates into your native language.

Save translations with Control-Return, browse your personal vocabulary with `wp :saved`, review it with `wp :review`, and export it with `wp :export`. Use `wp :clear` to clear recent lookup history without scrolling. Plain words such as `saved` and `review` remain normal lookups.

This release also improves acronym translation with a Youdao dictionary fallback and matches the pronunciation icon size to the translation icon.

Download the Apple silicon `.alfredworkflow` asset below and open it to install or update WordPing.

## 简体中文

WordPing 现在支持学习英语以外语言的用户。你可以选择母语和学习语言，在两者之间双向翻译；检测到第三种语言时，会翻译成你的母语。

按 Control-Return 保存译文；输入 `wp :saved` 浏览个人生词，输入 `wp :review` 复习，输入 `wp :export` 导出。使用 `wp :clear` 可直接清除近期查询记录。直接输入 `saved` 或 `review` 等普通单词时，仍会正常查词。

本版还通过有道词典回退查询改善缩略词翻译，并统一了发音图标与翻译图标的大小。

下载下方适用于 Apple 芯片 Mac 的 `.alfredworkflow` 文件，打开即可安装或更新 WordPing。
